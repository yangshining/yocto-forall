# Xilinx ZynqMP HARP DFE

This directory is the Product Integration for HARP DFE hardware built on the reusable `xilinx-zynqmp` Platform Integration.

## Current Target

| Target | MACHINE | Baseline | Default image | Support Level |
|---|---|---|---|---|
| `harp-dfe-xczu67dr` | `harp-dfe-xczu67dr` | `scarthgap` | `petalinux-image-minimal` | Parse-Validated |

Parse-Validated means CI parses the selected metadata. It does not claim a clean image build, hardware boot, or production support.

## Build

```bash
git submodule update --init --recursive
umask 0022
. configs/setup-env.sh -T harp-dfe-xczu67dr -p scarthgap
bitbake petalinux-image-minimal
```

Artifacts are expected under:

```text
build/scarthgap/harp-dfe-xczu67dr/tmp/deploy/images/harp-dfe-xczu67dr/
```

## Owned Content

- `hardware/system.xsa`: XCZU67DR hardware handoff.
- `meta-xilinx-zynqmp-harp-dfe/`: product MACHINE, device tree, firmware appends, kernel patches, and low-level initialization.
- `conf/local.conf.fragment`: XSA path, retained-work policy, and product packages.
- `targets/harp-dfe-xczu67dr.conf`: target identity and Support Level.

Reusable provider and XSCT-flow policy remains under `platforms/xilinx-zynqmp/`.

## Hardware Status

The checked-in XSA was generated by Vivado 2024.2 for `xczu67dr-ffve1156-2-i`. The archive contains hardware handoff and PS initialization data but no `.bit` entry. No FPGA bitstream recipe or active automatic U-Boot loading flow is currently implemented.
